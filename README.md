## معرفی Pani VPN

**Pani VPN** (پانی اتصالی امن به دنیای آزاد) یک کلاینت VPN امن، سریع و چندسکویی برای **Android، Windows، macOS و Linux** است که با رابط کاربری ساده و بدون تبلیغات، اتصال پایدار و خصوصی به اینترنت آزاد را فراهم می‌کند.

### ویژگی‌های کلیدی

- پشتیبانی از سیستم‌عامل‌های Android، Android TV، Windows، macOS و Linux
- اتصال سریع و پایدار بر بستر HTTP/1.1، HTTP/2 و HTTP/3
- مسیریابی هوشمند (Split Tunneling) برای وب‌سایت‌ها و برنامه‌ها
- پشتیبانی از TLS Fragmentation، پراکسی SOCKS5 و سرور رله
- DNS رمزنگاری‌شده (DNS over HTTPS)
- رابط کاربری چندزبانه همراه با تم روشن و تاریک
