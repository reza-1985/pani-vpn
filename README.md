## داستان Pani VPN

پشت نام **Pani VPN** یک داستان کوچک و واقعی است: **پانی**، سگ کوچک، پشمالو و بامزه صاحب این پروژه است که معمولاً از روی مبلِ خانه نگهبانی می‌دهد! هرچند پانی جثه کوچک و ظاهر پشمالویی دارد، اما وقتی پای اینترنت آزاد وسط باشد، مثل یک نگهبان سریع، وفادار و بدون تبلیغات راه را باز می‌کند و تنها با یک لمس شما را به دنیای آزاد وصل می‌کند.

### ویژگی‌های کلیدی
- در حال حاضر برای اندروید (Android) و ویندوز (Windows) آماده شده و به‌زودی برای سیستم‌عامل‌های دیگر هم منتشر می‌شود.
- پشتیبانی از پروتکل‌های HTTP/3، HTTP/1.1 و HTTP/2 برای اتصال سریع و پایدار
- مدیریت و جداسازی ترافیک (Split Tunneling) برای اپلیکیشن‌ها و وب‌سایت‌ها
- دور زدن محدودیت‌ها با TLS Fragmentation و پروکسی SOCKS5 داخلی
- پشتیبانی از DNS رمزگذاری‌شده (DNS over HTTPS) برای حفظ حریم خصوصی
- رابط کاربری ساده، سبک و بدون تبلیغات
